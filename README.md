# XELV — செல்வச் செய்திகள்

**Wealth news, first and fast.**

XELV is a professional digital newsroom covering money: gold prices, markets,
personal finance, insurance, government jobs & schemes, and technology —
in English with a full Tamil edition, personalised by the reader's location
(India, US, UK, UAE/Gulf, Singapore, Malaysia, Canada, Australia).

- Live wire headlines via Google News (headline + source + time; headlines open an on-site reader, no link out)
- Original articles from the XELV desks
- Gold-rate tables and EMI / SIP / currency calculators
- AdSense-safe trust pages: About, Contact, Privacy, Terms, Disclaimer,
  Editorial Policy, Corrections

## This repository

`index.html` is the current published snapshot of the site (6 Nov 2026
preview build). The live edition refreshes its Google News wire feeds daily.

Brand: XELV — coined from *Selvam* (செல்வம், wealth/prosperity).
Domain: xelv.in
